A manifest is a grouped set of parcels moving along similar routes. Couriers see manifests in the app based on their current location, vehicle type and capacity.

Tapping accept locks the manifest for the courier. The app provides turn-by-turn navigation between the pickup and destination lockers, without showing any recipient names or addresses.

If a courier can no longer complete a run, the manifest can be released back to the pool. This keeps the network efficient and deliveries on time.
