The Alvo API lets platforms, stores and fulfilment systems create parcels, track deliveries and manage batches programmatically. It is RESTful and returns JSON.

Core endpoints cover parcel creation, batch upload, label generation, status tracking and wallet balance. Webhooks are available for status and batch events.

Authentication is via API key. Contact the partnerships or support team to request access and sandbox credentials.
