API access is available to business and technology partners. Request a key through the contact or partners page with a short description of the integration.

Once approved, you receive sandbox credentials, documentation and a sample webhook payload. The sandbox lets you test parcel creation and tracking without affecting live data.

For production access, complete a brief review with the engineering team. This ensures the integration is secure and follows the privacy model.
