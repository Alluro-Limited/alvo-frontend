# frontend-design

Create distinctive, production-grade frontend interfaces with high design quality.

## When to use

- The user asks to build web components, pages, artifacts, posters, or applications.
- The user wants styling, beautifying, or a polished UI for any web output.
- The task is a website, landing page, dashboard, React component, or HTML/CSS layout.

## How to use

1. Reuse the shared design tokens in `@alvo/design-tokens` and primitives in `@alvo/ui`.
2. Do not build generic AI-looking UI. Use the Alvo palette, spacing, and radius tokens.
3. Build responsive, accessible, and clean interfaces.
4. Avoid inline styles; use Tailwind utilities.
5. Use `cn` from `cnfast` for conditional classes.
6. Run `bun run lint` and `bun run build` before finalizing.
