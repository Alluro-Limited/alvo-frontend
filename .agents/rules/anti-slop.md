# Anti-slop rules

- Do not add a dependency unless the project already uses it or it is required.
- Do not copy-paste large blocks; extract shared logic.
- Do not leave dead code, commented code, or unused imports.
- Do not hardcode strings, colors, or spacing in components.
- Do not use `console.log` in production code.
- Do not skip lint, tests, or react-doctor before committing.
- Do not add `TODO` comments without a plan; use tasks instead.
