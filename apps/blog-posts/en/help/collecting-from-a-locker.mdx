When a parcel arrives at its destination locker, the recipient gets an access code by SMS, email or app notification. There is no need to share a home address or wait at the door.

At the locker, enter the code, scan the QR on the app, or tap an NFC-enabled phone. The right compartment opens automatically, and the parcel can be collected in seconds.

If the code is lost, it can be regenerated from the app. The old code stops working immediately, so the parcel stays protected even if the message is shared by mistake.
