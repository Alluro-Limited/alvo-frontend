If an access code is lost, open the parcel in the app and choose 'regenerate code'. The previous code stops working immediately and a new one is sent to the recipient.

Only the sender or the registered recipient can regenerate a code. This prevents someone else from redirecting a parcel or opening the wrong compartment.

If the code does not arrive, check the phone number or email in the booking. Codes are sent by SMS and push notification.
