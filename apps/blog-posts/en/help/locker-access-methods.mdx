Alvo smart lockers support three access methods. QR codes open a compartment instantly when scanned from the app. One-time PINs work on the locker keypad for recipients without a smartphone.

NFC lets users tap a compatible phone against the locker. No app is required at the door, making collection faster in busy locations.

Each code is tied to a single parcel and a single use. If the code is lost, it can be regenerated from the app, invalidating the old one.
