Webhooks push event data to your endpoint as parcels and batches move through the network. This removes the need to poll the API for status changes.

Common events include parcel created, dropped, collected, in transit, delivered and batch validated. Each payload includes the tracking code, status and timestamp.

Set up a webhook URL in the developer dashboard. Alvo signs each request so your service can verify it came from the platform.
